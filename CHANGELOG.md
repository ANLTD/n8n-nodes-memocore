# Changelog

## 0.1.5

Memo Search can be limited to some projects with the new Project Names or IDs filter.

## 0.1.4

The Equals operator in row conditions can be picked from the list again. Before, n8n turned it into an empty expression.

## 0.1.3

Rows: new Get and Aggregate operations, tag and archive filters and a column choice for Query, and a title, summary, search hints, tags and lifetime for Create and Update.

## 0.1.2

Dates picked for a datetime column are sent in the workflow's time zone. Before, memocore refused them because they had no time zone.

## 0.1.1

Published from GitHub Actions through npm trusted publishing. No changes to the node.

## 0.1.0

First release with the Memo, Row, Project and Tag resources.
